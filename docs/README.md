# Documentação do simulador

Esta pasta reúne a documentação técnica usada para entender, executar e apresentar o simulador. A ideia é separar o que faz parte do núcleo do trabalho do que foi acrescentado apenas para facilitar o uso e a demonstração.

## Arquivos principais

- `arquitetura.md`: organização das classes e decisões do modelo.
- `requisitos.md`: relação entre os requisitos do trabalho e a implementação.
- `guia-apresentacao.md`: roteiro de estudo e demonstração do projeto.
- `interface-grafica.md`: funcionamento da interface Swing e do pacote para Windows.
- `doom.md`: integração opcional com Chocolate Doom.
- `ambiente-java.md`: versão de Java adotada e orientações de execução.
- `diagrama-classes.mmd`: diagrama de classes em Mermaid.
- `relatorio-tecnico.pdf`: relatório com arquitetura, métricas, experimentos e limitações.

Os arquivos `carga-apresentacao.txt`, `exemplo-apresentacao-eventos.txt` e `experimentos-apresentacao.csv` são exemplos usados durante a apresentação e para conferência dos resultados.

A documentação desta pasta corresponde à versão atual do projeto em Java 21.
